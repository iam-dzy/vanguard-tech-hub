# Vanguard Tech Hub website

- index.html: page structure and SEO tags
- css/styles.css: colours and layout (colours are at the top, under :root)
- js/config.js: EDIT THIS: WhatsApp number, phone, email, services, packages, projects, FAQs
- js/main.js: site logic (forms, WhatsApp links); rarely needs changes
- assets/images/: logos and project photos
- robots.txt, sitemap.xml: replace YOUR-DOMAIN with your real domain after publishing

Preview: double-click index.html.
Publish: upload this whole folder (or the zip) to Cloudflare Pages or Netlify.
